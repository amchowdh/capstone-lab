# Capstone Lab — Trivia Night

This repo is a capstone project that demonstrates the AI-driven development techniques taught across `session1-lab` through `session7-lab`, applied end-to-end to one small app ("Trivia Night").

This repo currently contains **planning only** — no app code has been written yet. Implementation is intended to happen in a separate conversation/session.

Start here:
- [docs/capstone-plan.md](docs/capstone-plan.md) — the master plan: app concept, architecture decisions, and the detailed 7-step build plan to execute.
- [docs/lab-ai-concepts-reference.md](docs/lab-ai-concepts-reference.md) — condensed reference of the specific AI/Copilot technique each of the 7 labs teaches (not the app code — the workflow).

When implementation begins, follow `docs/capstone-plan.md` step by step and author `CAPSTONE-GUIDE.md` at the repo root as you go, documenting what was actually run/produced at each step (mirroring the `.github/steps/*.md` style used in the other labs, but as a single narrative document).
